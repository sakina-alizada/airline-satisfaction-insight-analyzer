# Reflection

One of the most important lessons from this project was how significant the data preparation stage is in real data analytics work. Cleaning and preparing the dataset required more time than expected because survey data often contains inconsistent values, missing data, and categorical variables that must be properly encoded before they can be used in machine learning models.

Another key learning outcome was the value of comparing multiple models. Logistic Regression provided a simple and interpretable baseline model, while Random Forest achieved higher predictive accuracy. This comparison helped demonstrate how different algorithms capture patterns in the data differently and why model evaluation is an important part of the machine learning workflow.

Exploratory data analysis was also very valuable. Visualizations helped reveal patterns such as differences in satisfaction between travel classes and the strong influence of service‑related features like seat comfort and inflight entertainment. These insights helped guide the modelling stage and improved understanding of the dataset.

If I were to improve this project in the future, I would experiment with additional models such as gradient boosting and incorporate explainability techniques such as SHAP values to better understand individual predictions. I would also consider building an interactive dashboard to allow airline managers to explore the results more easily.

Overall, this project helped me better understand how to apply data processing, machine learning, and generative AI together in a complete analytics pipeline. It reinforced the importance of selecting tools that balance performance, interpretability, and practical usability when solving real‑world problems.
